# Prof. Dr. Necmettin Akdeniz — İletişim Sayfası

GitHub Pages üzerinde yayınlanmaya hazır, tek sayfalı statik site.

## Yayınlama

1. Bu klasördeki `index.html`, `assets` klasörü ve bu README dosyasını GitHub deposunun ana klasörüne yükleyin.
2. Depoda **Settings → Pages** bölümünü açın.
3. **Deploy from a branch** seçin; `main` dalı ve `/ (root)` klasörünü seçip kaydedin.
4. GitHub'ın verdiği Pages adresini açıp telefon görünümünde kontrol edin.

Google Fonts bağlantısı çevrimiçi yazı tiplerini yükler; bağlantı yoksa sistemdeki Georgia ve Arial yedekleri kullanılır. Doktorun sitesine veya alan adı ayarlarına değişiklik yapılmaz.
